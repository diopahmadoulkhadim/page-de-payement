KEB'S SPORT — PAGE D'INSCRIPTION ET PAIEMENT WAVE
=================================================

Fichiers :
- index.html : formulaire d'inscription et instructions de paiement Wave
- css/style.css : design responsive
- js/app.js : validation, copie du numéro Wave et envoi de la demande par WhatsApp

IMPORTANT AVANT PUBLICATION
1. Vérifier que le numéro +221 78 534 82 82 reçoit bien les transferts Wave et les demandes WhatsApp.
2. Le montant d'inscription à payer est de 2 000 FCFA. Vérifier le nom du bénéficiaire et le montant avant de confirmer chaque paiement.
3. La page ne vérifie pas les paiements et ne stocke pas les données sur un serveur.
   Le formulaire ouvre WhatsApp avec les informations pour que le club puisse vérifier la demande.
4. Le logo est chargé depuis le dépôt GitHub public existant :
   https://github.com/diopahmadoulkhadim/keb-sport
   L'ordinateur et le navigateur doivent être connectés à Internet pour l'afficher.

Pour tester : ouvrir index.html dans un navigateur ou publier le dossier sur un hébergement statique.
